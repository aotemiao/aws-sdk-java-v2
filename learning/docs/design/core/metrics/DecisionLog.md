## 2020-06-30

**来源：** 讨论 https://github.com/aws/aws-sdk-java-v2/pull/1926（metrics 配置设计）的会议

**出席：** Anna-Karin、Ben、Dongie、Matt、Nico、Zoe

**已关闭决策：**

1. 选项 1 应覆盖选项 2 还是追加？覆盖。这最符合直觉，也与多数类似设置一致。
2. 是否应从 SPI 返回 builder？否。暂无具体用例；若未来需要可再增加接受「配置」对象的方法。
3. 布尔型环境变量是否应同时支持大小写？与我们在其他处的做法保持一致。一致性是核心原则之一。
4. 是否应支持 profile 文件设置？否。不希望像 CLI 那样引入任意 SDK 专属属性；若客户有需求可再探索。
5. 是否应使用 ServiceLoader？是。与 HTTP 客户端发现机制一致，且使模块不必始终在 classpath 上。
